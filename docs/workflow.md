🚀 기존 모델을 활용한 반자동 라벨링 워크플로우

1. 로컬 IDE에서 1차 추론 (Inference) 돌리기
질문자님이 IDE에서 파이썬 스크립트를 작성하여, 기존 커스텀 모델에 340장의 신규 이미지를 밀어 넣고 추론(Detect)을 실행합니다. 이때 추론 결과(Bounding Box 좌표)를 이미지 이름과 동일한 .txt 파일(YOLO 포맷)로 일괄 저장하도록 코드를 짭니다.

2. 이미지와 TXT 파일을 한 폴더에 모으기
신규 이미지 340장과 방금 스크립트가 뱉어낸 340개의 텍스트 파일(.txt)을 하나의 로컬 폴더에 예쁘게 모아둡니다. (이때 새로 짠 data.yaml 파일의 클래스 인덱스와 텍스트 파일의 클래스 번호가 일치해야 합니다.)

3. VisoLabel에서 불러오기 (Import)
해당 폴더를 VisoLabel 프로젝트로 불러옵니다. 그러면 기존 모델이 1차로 추론해서 잡아낸 박스들이 화면에 이미 다 그려진 상태로 나타납니다.

4. 인간 지능으로 검수 및 수정 (Human-in-the-loop)
처음부터 마우스 드래그로 박스를 그릴 필요가 전혀 없습니다. 화면을 휙휙 넘기면서 기존 모델이 미처 못 잡았거나(False Negative), 엉뚱한 걸 잡은 것(False Positive)들만 마우스로 쓱쓱 지우거나 크기를 수정해 줍니다.

5. 최종 Export 및 스크립트 학습
340장 검수가 끝나면 VisoLabel에서 최종 데이터셋을 Export 한 뒤, 기존 데이터셋과 합쳐서 IDE에서 직접 학습 스크립트를 돌리시면 됩니다.
